# CareerPath AI Architect

## Overview

A full-stack AI-powered career intelligence platform. Users build a professional profile, set a 5-year career target, and run an AI analysis that produces a readiness score, gap report, 5-year roadmap, and auto-generated milestones.

pnpm workspace monorepo using TypeScript.

## Stack

- **Monorepo tool**: pnpm workspaces
- **Node.js version**: 24
- **Package manager**: pnpm
- **TypeScript version**: 5.9
- **Frontend**: React + Vite + Tailwind CSS v4 (dark navy/cyan futuristic design)
- **UI Components**: shadcn/ui
- **API framework**: Express 5
- **Database**: PostgreSQL + Drizzle ORM
- **Auth**: JWT (stored in localStorage, injected via Bearer token)
- **Validation**: Zod (`zod/v4`), `drizzle-zod`
- **API codegen**: Orval (from OpenAPI spec)
- **Build**: esbuild (CJS bundle)

## Artifacts

- `artifacts/careerpath-ai` — React+Vite frontend at `/` (port 21588)
- `artifacts/api-server` — Express 5 API server at `/api` (port 8080)

## Key Commands

- `pnpm run typecheck` — full typecheck across all packages
- `pnpm run build` — typecheck + build all packages
- `pnpm --filter @workspace/api-spec run codegen` — regenerate API hooks and Zod schemas from OpenAPI spec
- `pnpm --filter @workspace/db run push` — push DB schema changes (dev only)

## Frontend Pages

- `/` — Landing page
- `/login` — Login (JWT auth)
- `/register` — Registration
- `/onboarding` — 5-step onboarding wizard (basics, work, education, skills, career goal)
- `/dashboard` — Command Center with readiness score, skill gaps, activity log
- `/profile` — Full profile editor (personal, work history, education, skills, certifications)
- `/career-goal` — 5-year career target setup
- `/analysis` — Run AI analysis, view gap report and readiness score
- `/roadmap` — 5-year career roadmap with 4 phases
- `/milestones` — Milestone tracker (auto-generated by analysis)
- `/history` — Analysis run history with score progression

## API Routes

All protected routes require `Authorization: Bearer <token>` header.

- `POST /api/auth/register` — register (name, email, password)
- `POST /api/auth/login` — login → returns JWT token
- `GET /api/auth/me` — current user
- `GET /api/profile` — get profile
- `PATCH /api/profile` — update profile
- `GET /api/profile/completion` — profile completion %
- `GET/POST /api/work-experiences` — list/create work experience
- `PATCH/DELETE /api/work-experiences/:id` — update/delete
- `GET/POST /api/education` — list/create education
- `DELETE /api/education/:id` — delete
- `GET/POST /api/skills` — list/create skills
- `DELETE /api/skills/:id` — delete
- `GET/POST /api/certifications` — list/create certifications
- `DELETE /api/certifications/:id` — delete
- `GET/PUT /api/career-goal` — get/set career goal
- `POST /api/analysis` — run analysis (generates score + milestones)
- `GET /api/analysis/latest` — latest analysis result
- `GET /api/analysis/history` — all past analyses
- `GET /api/roadmap` — 4-phase roadmap from latest analysis
- `GET /api/milestones` — list milestones
- `PATCH /api/milestones/:id/complete` — mark milestone done
- `GET /api/dashboard/summary` — dashboard stats
- `GET /api/dashboard/skill-gaps` — skill gap list
- `GET /api/dashboard/activity` — recent activity log

## Auth Notes

- JWT secret: `JWT_SECRET` env var (falls back to hardcoded dev value)
- Token stored in `localStorage` under key `careerpath_token`
- `setAuthTokenGetter` from `@workspace/api-client-react` injects Bearer header on all API calls

## Codegen Notes

- After running orval codegen, the script overwrites `lib/api-zod/src/index.ts` with `export * from "./generated/api";` to avoid duplicate export errors
- All generated hooks are in `lib/api-client-react/src/generated/api.ts`
