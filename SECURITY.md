# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability or include credentials,
tokens, personal data, or exploit details in a public discussion.

Use GitHub's private vulnerability reporting feature for this repository. Include
the affected route or component, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within five working days.

If private vulnerability reporting is unavailable, contact the repository owner
privately through their GitHub profile before sharing technical details.

## Supported Version

Security fixes are applied to the current production version on the default
branch. Older commits and local forks are not supported.
